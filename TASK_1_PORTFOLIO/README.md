# Personal Portfolio Website

## Overview

This project is a Personal Portfolio Website developed using HTML and CSS. It is designed to showcase personal information, technical skills, projects, and contact details in a clean and responsive layout.

The website serves as an introductory web development project and demonstrates the fundamentals of structuring and styling web pages using HTML and CSS.

---

## Features

* Header section with name and tagline.
* About section with profile image and short biography.
* Skills section displaying technical skills and expertise.
* Projects section showcasing sample projects with descriptions and images.
* Resume section with a downloadable PDF resume.
* Contact section containing email address and phone number.
* Footer section with copyright information and additional details.

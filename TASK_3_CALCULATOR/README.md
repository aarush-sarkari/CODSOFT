# TASK 3 - Calculator

This project is a simple and responsive calculator built using HTML, CSS, and JavaScript as part of the CodSoft Web Development Internship.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage Calculation
- Clear Button
- Delete Button
- Responsive Grid Layout
- Interactive User Interface

## Folder Structure

```
TASK_3_CALCULATOR
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Open the project folder.
2. Open index.html in your browser.
3. Use the calculator to perform arithmetic operations.
